# LinkedIn Standards

## Headline (~220 characters)

Structure: **Primary title | Specialty | Value or differentiator**

- Include 2–3 recruiter-searchable keywords
- One clear lane — avoid stacking three equal titles
- Location or geography if relevant to search

## About Section

- Line 1: Positioning statement (role + years + domain)
- Lines 2–4: Proof points from real experience
- Include technical focus without tool-dump opening
- Optional CTA if user is actively searching

## Experience

- Mirror resume facts; expand with context LinkedIn allows
- Current role must have description — highest recruiter weight
- 3–5 bullets for recent roles; shorten older roles

## Skills

- Recommend Top 3 pinned skills aligned to `memory/career-goals.md`
- Remove irrelevant or mis-tagged skills that dilute positioning
- Target 30–50 focused skills, not hundreds of fragments

## Featured / Projects

- Feature recent, high-credibility work only
- Close or date stale "Present" projects
- Pin thought leadership, certifications, or portfolio links when relevant

## Recruiter Search

Headline and About must contain exact phrases recruiters filter on for target roles.
