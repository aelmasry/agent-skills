# Archived skills

Skills in this directory are **not** symlinked into `~/.cursor/skills/` by `install.sh` / bootstrap.

They remain in git for recovery and explicit invocation (e.g. `@skills/_archive/penetration-tester`).

See [docs/SKILLS_MATRIX.md](../../docs/SKILLS_MATRIX.md) for why each skill was archived (merge absorb vs defer).

Do not add new active skills here. Move a skill here only as part of a documented matrix change.
