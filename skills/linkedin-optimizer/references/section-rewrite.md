# Headline / About / Experience rewrite (adapted)

Adapted from [sergebulaev/linkedin-skills](https://github.com/sergebulaev/linkedin-skills)
(`linkedin-profile-optimizer`, MIT). Recruiter search and resume alignment still
win when they conflict with "use every character" or question-hooks.

Voice: `personal-brand`. Facts: `ali-career-profile` + master resume.
DISCUSSION-MODE: score + 2 headlines first; full rewrites only when asked.

## Headline (~220 chars)

**Default (jobs / recruiter search)** — keep this:

`[Primary title] | [Specialty] | [Outcome or domain]`

One primary lane. Searchable title first. No stacked equal titles.

**Option B (inbound consulting)** — only when the goal is clients more than search:

`[What you do] | [Who you help] [achieve what result]`

Still include at least one recruiter-searchable role noun (AI Engineer,
Solutions Architect, or similar). No "passionate" / "driven" / emoji chains.

Always deliver **two** Headline options labeled A (search) and B (consulting).

## About (7-step)

First **two lines** must carry recruiter keywords (visible before "see more").
Hook = claim or number, **not** a question.

| Step | Purpose |
|------|---------|
| 1. Hook | Claim or number that also contains the primary lane keywords |
| 2. Role | What Ali actually does and who he helps |
| 3. Proof | One or two production wins (resume-true numbers only) |
| 4. Value | Problem → how he works (architecture / production AI, not demo hype) |
| 5. Human | One line, no fluff |
| 6. Specialties | Search keywords (truthful tool/domain list) |
| 7. CTA | Freelance/consulting last line if relevant; otherwise a specific next step |

Flag any number not in the resume with `[confirm before pasting]`.

## Experience

Formula: `[Action verb] + [specific metric]` when the metric is true.

Strong: Led, Built, Shipped, Cut, Scaled, Rebuilt, Delivered.
Avoid: Responsible for, Worked on, Helped with, Participated in.

- Current role: real description, highest weight, 3–5 bullets
- Older roles: shorter
- Dates/titles match the resume
- If there is no defensible metric, use a concrete scope/system instead of inventing one
