# LinkedIn Visibility Checklist

## Profile (recruiter search)

### Headline (~220 chars)

- [ ] Primary searchable title first (e.g. AI Engineer | Solutions Architect)
- [ ] One differentiator (production AI, scalable systems — factual)
- [ ] Not a stacked list of 4 equal jobs
- [ ] Keywords recruiters filter: AI, Architecture, Backend as relevant

Formula: `[Primary title] | [Specialty] | [Outcome or domain]`

### About

- [ ] First 2 lines carry keywords (visible before "see more")
- [ ] Proof points from real production work
- [ ] Architecture / systems thinking tone
- [ ] **Freelance CTA** last line if consulting-first, e.g.  
  `Open to select consulting: production AI systems, architecture reviews, backend platforms. Message me with context.`

### Experience

- [ ] Current role has a real description (highest weight)
- [ ] 3–5 bullets on recent roles; shorter on older
- [ ] Aligns with resume dates/titles

### Skills

- [ ] Top 3 pinned match target lane
- [ ] 30–50 focused skills; prune noise
- [ ] Endorse-attracting skills you can defend in a call

### Featured

- [ ] Case study / repo / article with architecture or AI depth
- [ ] No stale "Present" projects without outcomes
- [ ] Optional: Services / portfolio link

### Freelance discoverability

- [ ] LinkedIn Services offer (one clear package) if using Services
- [ ] Creator mode optional — only if posting consistently
- [ ] Open to Work: use carefully; prefer Services + About CTA for consulting brand

## Visibility plan (keep light)

Max **2 posts per week**. Topic seeds (not full drafts):

| Slot | Pillar | Example angle |
|------|--------|----------------|
| 1 | Production AI | RAG failure mode you fixed (no confidential data) |
| 2 | Architecture | Trade-off you made and why |

Rules:

- Native posts; link in comments if needed
- Reply in first hour
- Goal metrics: profile views from ICP, inbound DMs — not likes

For full post writing, use `linkedin-content-creator`.
