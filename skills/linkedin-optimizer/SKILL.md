# LinkedIn Optimizer

## Goal

Improve **recruiter and client discoverability** for:

- AI Engineering
- Solutions / Software Architecture
- Backend Engineering
- Technical Leadership
- **Jobs + clients inbound** (FT/PT recruiters and consulting — CTA matches `target-profile.md`)

Optimize for reputation and relevance — not vanity likes.

## Inputs required

| Required | Optional |
|----------|----------|
| Current Headline + About (paste) | Full Experience sections |
| Target lane (AI / Arch / Backend) | Skills list / Featured |
| | Master resume for fact alignment |

## Workflow

1. **Audit** — Headline, About, Experience, Skills, Featured against [visibility-checklist.md](visibility-checklist.md)
2. **Keywords** — Recruiter-searchable phrases from [keyword-clusters-ai-arch.md](../cv-jd-matcher/keyword-clusters-ai-arch.md) (truthful only)
3. **Rewrite sections** — Copy-ready Headline (2 options), About, current-role bullets, Top 3 Skills to pin
4. **Featured strategy** — 2–3 high-signal items (case study, repo, article, cert)
5. **Freelance signal** — Clear consulting CTA if freelance-first (Services + About last line)
6. **Visibility plan** — Max **2 posts/week**; use [visibility-checklist.md](visibility-checklist.md). Draft short post topics here; full calendars live in archived marketing skills if needed.

## Non-negotiable rules

- Align LinkedIn with resume facts — no contradictions
- One primary lane in Headline (not three equal titles)
- No buzzword salad ("passionate", "guru", "disruptor")
- Prefer production AI + architecture language over demo hype

## Output format (always)

```
1. Overall assessment
2. Strengths
3. Weaknesses
4. Missing keywords (vs stated goal)
5. Recruiter / client search recommendations
6. Improved sections (Headline ×2, About, Experience, Skills, Featured)
7. Visibility plan (2 posts/week max — topics only unless asked to draft)
8. Freelance CTA / Services suggestion (if relevant)
9. What changed and why
```
