# Hook formulas (adapted)

Adapted from [sergebulaev/linkedin-skills](https://github.com/sergebulaev/linkedin-skills)
(`linkedin-post-writer` / `references/hook-formulas.md`, MIT). Skeletons only.
Voice, length, and cadence stay Ali-specific (`personal-brand`, DISCUSSION-MODE).

Do not dump this catalog unsolicited. Offer **2–3** formulas that fit the idea,
then wait. Draft only after Ali picks (or says draft).

**Hard constraints (always):**
- Line 1 is a statement or a number, never a question. Question goes at the close.
- Prefer a specific, truthful number or named fact in the first 1–2 lines.
- Pay off any teaser within 2 lines. No "what nobody tells you" / "plot twist".
- One contrast per post. No comment-gate ("comment X to get Y") unless Ali asks.
- F6 only if Ali explicitly wants a lead magnet with a real, named deliverable.
- Length: 150–300 words, not long-form thought-leadership essays.

| Goal | Prefer |
|------|--------|
| Comments | F4, F9, F10, F17, F18 |
| Saves | F7, F8, F15, F19 |
| Likes | F11, F13, F16 |
| Reposts | F2, F14, F20 |

---

### F1 — Platform Risk Anaphora
Repeat `{X} can {restrict you}` across platforms, then: you rent attention, you don't own the feed. Close with what Ali actually changed in his stack.
Use for: tool lock-in, vendor risk, local vs cloud.

### F2 — R.I.P. Category Obituary
`R.I.P. {category}. Cause of death: {mechanism}.` Dated evidence, then who actually won.
Use for: hype cycles Ali has lived through. Skip if it would read as guru-obituary.

### F3 — Year-over-Year Pivot
`In {year}, I {humble benchmark}. In {this year}, I'm {specific goal}.` Line 3 = first real number.
Use for: career / stack shifts Ali can prove.

### F4 — Time-Anchor Confession
`{N} {days|months} ago, I stopped {behavior}.` Immediate cost with a number. No "let me be honest".
Use for: a real stop Ali made (a tool, a process, a posting habit).

### F5 — Self-Proving Meta
Claim + public test for the next 24h. Reader verifies, not "comment YES".
Use sparingly. Must be a real test Ali will run.

### F6 — Comment-Gate Lead Magnet
**Default: skip.** Only if Ali asks. Named bundle that exists today. Ask a real question; send the file to people who answer. Never "comment KEYWORD".

### F7 — Odd-Precision Money Ledger
Odd number as line 1 (`$873.47`, `41GB`, `14 min`). Line-item breakdown, what it replaced, what broke.
Use for: infra cost, local LLM vs API, disk cleanup. Numbers must be Ali's.

### F8 — Paid-vs-Free Reversal
`I charge {X} for {this}. Today, the checklist is here.` Named steps Ali actually runs.
Use for: architecture review / RAG eval methods. Soft CTA, not "comment READY".

### F9 — Curiosity-Gap Teaser
Incomplete line 1–2, **concrete reveal in line 3** (name or number) before the fold.
Use for: a real emergent behavior in logs/tools. No empty tease.

### F10 — Contrarian + Historical Receipts
Sacred cow + dated "death" predictions, then the counter-stat Ali can defend.
Use for: "AI will replace developers" and similar. One contrast only.

### F11 — Emotional Cold-Open
Start at the peak of a **true** scene. No ALL CAPS. Date/place/number in the first two lines.
Use for: a real outage, a failed deploy, a hard call. Skip if the story isn't Ali's.

### F12 — Permission Slip
Reassurance with one dated fact from Ali's record. Once in a while, not a weekly mode.
Use for: career-transition anxiety. Must not be motivational fluff.

### F13 — Bait-and-Switch Reversal
`No more {practice}.` Beat. Reveal: it was an upgrade, with a number.
Use for: process cuts that actually improved the system. Must resolve positive.

### F14 — Named Gratitude
Name real people for a concrete act. Honor them, not Ali.
Use only with people Ali is willing to tag.

### F15 — Explain-to-Kids
`{Term} in plain language.` Short glossary, technically correct.
Use for: RAG, agents, orchestration — Ali's terms, not condescension.

### F16 — Status-Strip Humility
Title outside vs a specific humbling scene. Genuine deflation, not humble-brag.

### F17 — Controlled A/B Anecdote
`{Action A} → {outcome A}. Same action, one variable changed → {outcome B}.`
Exactly one variable. Operational question at the close.

### F18 — False-Binary Dissolve
Everyone picks A or B. Kill both with a shared flaw. Third option Ali actually shipped.
Do not pair with F20 in the same post. No strawman binary.

### F19 — Anecdote-Meets-Evidence
Small first-person noticing, then 2–3 sourced/true numbers, then the decision Ali made.
No fabricated stats. If no numbers, use F4 instead.

### F20 — Diverging-Curves Close
Two approaches that look similar now; they diverge on a timeline. One maxim.
Often a close, not a full post. Don't stack on F18.

## Never (Ali + feed)

- Question as the first line
- "Here's what nobody tells you" / "The result?" / "Plot twist"
- All-caps first line
- External links in the body (first comment if needed)
- Invented metrics, fake vulnerability, confidential Seddiqi/employer detail
