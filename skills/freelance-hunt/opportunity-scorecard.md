# Opportunity Scorecard (FT / PT / Freelance / Client)

Score each dimension 1–5. Max = 30.

## Shared dimensions

| Dimension | 1 | 3 | 5 |
|-----------|---|---|---|
| **Skill fit** | Wrong lane | Adjacent | Core AI / Arch / Backend |
| **Scope / role clarity** | Vague | Rough | Clear outcomes or JD |
| **Comp signal** | Unpaid / no clue | Soft range | Clear band or serious budget |
| **Timeline realism** | Impossible | Tight | Realistic |
| **Counterparty quality** | Scam / no web | Average | Credible company / referral |
| **Engagement fit** | Misaligned (e.g. wants junior) | OK | Matches target seniority + type |

## Type-specific notes

### Full-time / Part-time

- Weight **role clarity** and **skill fit** highest.
- Red flags: endless “must have” unicorn list; title inflation without scope.
- On **Go** → next step is `cv-jd-matcher` (CV + cover letter + ≤7-day plan).

### Freelance / contract

- Weight **scope clarity**, **budget**, **engagement type** (phased SOW > open-ended).
- Red flags: unpaid trials, “send full source first”, unlimited revisions for tiny fee.

### Potential client (no formal JD yet)

- Weight **counterparty quality** and **problem fit**.
- Score **scope** on how well you can guess a first discovery call.
- Output = outreach + discovery questions, not a full proposal yet.

## Interpretation

| Total | Default recommendation |
|-------|------------------------|
| 24–30 | **Go** |
| 18–23 | **Negotiate** — clarity, rate/comp, or scope first |
| &lt; 18 | **No-go** — unless strategic (referral, brand, rare domain) |

Document any strategic override.

## Positioning lanes (default)

1. Production AI implementation / RAG / agents  
2. Solutions / software architecture  
3. Backend / platform consulting or ownership roles
