# 7-Day Fit & Interview Plan (max)

Always include a **short plan ≤ 7 days**. If the interview is in N days and N < 7, compress to N days.

## Purpose

1. Close **truthful** fit gaps before / right after apply (vocab, proof, demos — not fake skills).
2. Prepare for interview on the JD’s real themes.

## Default template

| Day | Focus | Output |
|-----|--------|--------|
| 1 | Finalize tailored CV + cover letter; submit if ready | Files sent / application logged |
| 2 | Deep-read JD + company product; list 5 themes | Notes |
| 3 | STAR stories × 5 (from achievements-log) | Spoken aloud once |
| 4 | Technical drill: top gap area (e.g. RAG evals / system design) | 2 practice answers |
| 5 | Architecture / case: whiteboard one end-to-end design for their domain | Diagram + trade-offs |
| 6 | Behavioral + leadership; questions to ask them | 5 Qs ready |
| 7 | Mock pass (45 min); light review of gaps that remain | Confidence check |

## Compression rules

- **Interview in 2–3 days:** Days 1+3+4+7 only (submit, STAR, top technical gap, mock).
- **Already applied:** Skip Day 1 submit; start with themes + STAR.
- **Gaps that cannot close in a week** (e.g. missing years of Kubernetes): label as **interview honesty plan** — how to answer without claiming false ownership — do not invent study that pretends mastery.

## Daily time budget

Suggest **60–90 minutes/day** unless user asks for heavier load. Prefer focused reps over long reading lists.

## What not to include

- Multi-week courses
- Vague “improve LinkedIn”
- More than 3 study topics in the week
