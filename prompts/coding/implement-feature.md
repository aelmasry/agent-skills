# Implement a feature incrementally

Use skills: `incremental-implementation`, `test-driven-development`.

## Context
- Spec: SPEC.md (or describe the feature below)
- Scope: one vertical slice at a time

## Instructions

1. Read the spec and relevant existing code
2. Pick the next pending task (or the smallest end-to-end slice)
3. Write a failing test for expected behavior (RED)
4. Implement minimum code to pass (GREEN)
5. Run full test suite and build
6. Commit with a descriptive message
7. Stop and report what changed — do not start the next task unless asked

## Acceptance
- Tests pass, build succeeds, no unrelated changes
- File:line references in the summary
