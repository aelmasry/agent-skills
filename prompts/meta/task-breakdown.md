Use skill: `planning-and-task-breakdown`.

## Input
- Spec: SPEC.md or description below
- Goal: <!-- what "done" looks like -->

## Instructions

1. Plan mode only — no code changes yet
2. Map dependency graph between components
3. Slice vertically (complete user-visible paths, not layers)
4. Each task: title, acceptance criteria, verification step
5. Add phase checkpoints for human review

## Output

Save to:
- `tasks/plan.md` — narrative plan with dependencies
- `tasks/todo.md` — checkbox list ordered by dependency

Present a short summary and ask for approval before implementation.
