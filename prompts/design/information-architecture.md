# Information architecture — structure before pixels

Use skills: `ux-researcher`, `ux-architect`, `product-manager`.

Define navigation, content hierarchy, and user flows before visual design or code.

---

## Input
- Brief or feature description
- Existing site/app structure (if brownfield)

## Deliverables

1. **Site map** — pages/screens and parent-child relationships
2. **Primary navigation** — top-level items, max 5–7
3. **User flows** — 2–3 critical paths step-by-step
4. **Content hierarchy** — what users see first, second, third per page
5. **URL/routing plan** — RESTful, predictable patterns

## Rules

- Mobile-first navigation (how does nav work at 375px?)
- One primary CTA per page
- Label with user language, not internal jargon
- Flag content that needs search, filters, or pagination

Save to `.design/<feature>/INFORMATION_ARCHITECTURE.md` and confirm before design tokens or build.
